# Frontend

React UI for uploading CSV files, selecting datasets/columns, and visualizing them with line, bar, or pie charts.

## Scripts
- `npm run dev` — start Vite dev server (defaults to port 5173)
- `npm run build` — production build
- `npm run preview` — preview the production build

Configure the API target with `VITE_API_URL` if the backend runs on a different host/port (default is `http://localhost:4000`).
